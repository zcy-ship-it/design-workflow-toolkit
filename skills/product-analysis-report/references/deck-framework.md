# Product-analysis deck framework

Use this as a modular page library, not a mandatory script. Merge or split pages according to available evidence and requested length.

## 30-page default

| Page | Purpose | Required output |
|---:|---|---|
| 1 | Cover | Product name, proposition, project type |
| 2 | Journey map | Whole reasoning path and current decision |
| 3 | Brief | Design question, user, context, boundaries |
| 4 | Value definition | Functional, emotional, social, or strategic value |
| 5 | Concept formula | Factors that constrain the proposition |
| 6 | Method | Evidence-to-concept workflow |
| 7 | Key insight | One evidence-backed problem reframing |
| 8 | Opportunity field | Strategic axes or opportunity map |
| 9 | Divergent directions | 6–10 distinct mechanisms or propositions |
| 10 | Divergence evidence | Sketch board, morphological matrix, or experiment |
| 11 | Shortlist | 3–5 directions and their hypotheses |
| 12 | Selection logic | Criteria, evidence, risks, and provisional ranking |
| 13 | Synthesis | Which directions combine and why |
| 14 | Early concept | First integrated product or system proposition |
| 15 | Reference study | Relevant structural, behavioral, or contextual precedents |
| 16 | Principle study A | First extracted design rule |
| 17 | Principle study B | Second extracted design rule |
| 18 | Reduction | What is retained, transformed, and removed |
| 19 | Turning point | Contradiction and scope-changing decision |
| 20 | Redefined object | New design focus and product boundary |
| 21 | Core concept | Memorable concept and causal logic |
| 22 | Product architecture | Parts, modules, interfaces, and relationships |
| 23 | State logic | Complete, partial, changed, inactive, or failure states |
| 24 | Scenarios | Normal, interactive, and exceptional use |
| 25 | Design language | Geometry, structure, CMF, light, and prohibited clichés |
| 26 | Scheme A | Principle, architecture, advantage, risk |
| 27 | Scheme B | Principle, architecture, advantage, risk |
| 28 | Scheme C | Principle, architecture, advantage, risk |
| 29 | Final decision | Comparable matrix and strategic choice |
| 30 | Next validation | Prototype plan, success criteria, and decisions affected |

## Page-writing formula

For each page, write a conclusion title, 1–3 supporting evidence items, a specified visual form, and one takeaway that connects to the next page.

## Flexible lengths

- **10–12 pages:** brief, insight, formula, divergence, shortlist, turning point, concept, architecture/scenario, schemes, decision, validation.
- **15–20 pages:** add evidence, selection matrix, synthesis, state logic, and form rules.
- **25–35 pages:** use the 30-page default; expand only research evidence, mechanism studies, prototypes, and comparisons.
- **40+ pages:** divide into research, strategy, concept, design, engineering, and validation chapters. Add appendix evidence rather than repeating the narrative.

## Anti-copy boundary

From a reference deck, extract only transferable properties such as pacing, information density, section rhythm, grid behavior, or comparison logic. Do not reuse its subject-specific claims, conclusions, names, slogans, wording, cultural interpretations, examples, sketches, diagrams, photographs, motifs, scores, or decisions. Rebuild all content from the user's current product evidence.
