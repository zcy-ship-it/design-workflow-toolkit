# 备赛工具与新生训练

## 一张可填写的论证卡

| 项目 | 要写清的内容 |
|---|---|
| 主张 | 一句有范围、可被反对的话 |
| 负担 | 此卡具体证明持方的哪一部分 |
| 前提 | 需要成立的事实、价值理由及适用条件 |
| 推理桥梁 | 为什么这些前提能支持主张；是否还藏着一个前提 |
| 证据 | 来源、语境、能支持什么、不能支持什么 |
| 影响 | 谁受影响、如何改变、何时发生 |
| 比较 | 相比何种可行替代方案；为何更值得选择 |
| 防守 | 最强异议、可承认处、修改后剩余结论 |

卡片用于补缺口，不要求每次发言把每栏逐字说一遍。

## 教学示例：应不应该鼓励大学新生广泛尝试不同社团

本例为虚构练习，不是新国辩真实赛题，也不包含已核实的经验数据。

**原始论点**：“应该，因为尝试越多，越能找到热爱。”

**诊断**：把尝试数量与找到适合领域之间的关系说成单调增长；没有区分低成本探索与深度承诺；没有处理精力挤占，也没有说明鼓励政策的边界。

**较强版本**：对于偏好尚不明确的新生，校方可以鼓励有时间上限、允许退出的初步体验。理由是新生对活动的认识可能不足，实际体验能够提供新的自我认识；若退出成本可控，这种探索可能改善后续选择。但它是否值得鼓励，仍需证明信息增益与机会成本的比较。

**新增的规范前提**：大学应在不显著损害基本学习与身心状态的条件下，支持新生形成自主选择能力。这是建议补充的理由，需辩护，不能伪装成原论点已有。

**待核实**：新生偏好不确定程度、体验是否带来有效信息、投入时间和退出成本、相对于信息介绍或定向咨询的增益。不得虚构研究来填满。

**对方最强版本**：注意力有限，广泛尝试可能造成碎片化；深入投入才能突破入门挫折并形成能力。争点是何种探索强度值得鼓励，以及探索与深入的机会成本，而不是“要不要让新生拥有兴趣”。

**判准候选**：哪一种倡导更有助于新生在可承受成本下形成自主且可持续的投入。必须解释为何题目应重视自主和可持续，而不是直接声称此判准天然正确；学业、身心底线及不同学生条件也应纳入。

**质询分支**：

- 目标：确认对方反对的是高成本分散投入，还是也反对有上限的体验。
- 主问：“如果体验不要求长期承诺，您的机会成本批评还成立在哪个环节？”
- 承认成本下降：追问剩余成本，并比较与所得信息的关系。
- 否认成本下降：请说明实际成本由何产生，是否所有体验都如此。
- 加条件：记录条件，检验本方方案是否满足，而不是直接宣布对方认输。
- 回收：“目前分歧缩小为体验的实际时间成本与信息收益；本方仍需证明后者更值得。”

注意：不能临时添加任意理想条件让本方永远免疫。若辩题只讨论一般倡导，应说明本方限定是否符合通常情形，并回应倡导在现实中可能被误用的风险。

## 六种短练习

1. **一分钟审题**：让学生说清评价主体、行为、比较对象和负担。反馈一个最关键的范围问题。
2. **补桥梁**：给一个“事实→应该”的跳步，让学生补规范前提；再问这个前提为什么值得接受。
3. **钢人练习**：让学生先说对方最有力的一分钟理由，再选一个真正影响结论的回应点。
4. **判准压力测试**：换边后是否还能使用同一标准？若不能，检验是否偷渡结论，而非立即认定标准无效。
5. **质询分支**：导师分别扮演承认、否认、加条件三种回答，练习跟进；每轮只反馈问题的清晰度与回收是否成立。
6. **比较结辩**：给双方各一项已经成立的利益，让学生在一分钟内解释为什么一项更重要；不许假装对方利益不存在。

用户没有要求直接给答案时，先布置一个可完成的小任务，等学生回答后诊断；卡住时依次给提示、半成品、示范，并让学生换一个例子迁移运用。

## 按剩余时间安排

- **只有一小时**：确认题意和主线，补最致命跳步，准备最强反驳及回应，口头跑一次。资料缺口明确标注。
- **一天**：双方各搭主线，核实核心材料，完成攻防与质询，至少一次计时排练，按暴露的缺口修改。
- **一周**：前期探索与选线，中期证据核验和交叉攻防，后期计时模辩、复盘与精简。依据队员实际空闲拆任务，不机械按天填满。

每项任务写出负责人（未知则待分配）、交付物、验收条件和期限。例如“找到原始调查并说明样本与局限”，优于“搜十条资料”。

|---|---|---|---|---|---|

将“没准备到”“准备了没说出”“说出但没证明”“证明后没比较”“比较了但表达不清”分开。先修最影响结论的一项，不因输赢倒推每个操作都正确或错误。
