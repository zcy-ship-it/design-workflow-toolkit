# 方法定位与来源边界

## 使用方式

本 skill 是面向新生的原创教学综合：将争点、论证责任、推理桥梁、判准辩护、钢人化、影响比较、质询分支与渐进训练结合。上述框架是教学设计，不声称由新国辩官方发布，也不声称所有参赛队伍或评委采取同一方法。

“新国辩风格”在此指重视有内容的正面交锋与理由比较的训练方向，不指模仿某位辩手的口癖、堆叠金句、固定价值升华或追求压迫感。风格不能代替事实与推理。

## 后续分析比赛材料的约束

本次尝试读取官方比赛视频页面遇到访问限制，未观看比赛、未取得字幕，因而没有基于未观看内容提炼辩手表现、评委观点或具体经典交锋。

若用户提供比赛链接、字幕、稿件或评委点评：

1. 确认出处、场次、持方及可读范围。无法访问时请用户贴出相关片段，继续处理已经可见的内容。
2. 用时间戳或原文定位“主张—回应—再回应—剩余分歧”，把分析与原话分开。
3. 将单场策略限定为个案，不由一段名场面推导全赛事固定风格。
4. 评委点评是该场评价材料；区分个人理由与赛事章程。
5. 精确引文须核对原文；不编造辩手、评委的“经典语录”。
